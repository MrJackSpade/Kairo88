# Add a game

Add a game the catalog doesn't know, such as your own copy of a multi-disk game, and set it up yourself: group its disks, name it, choose which disk goes in each drive, and play. Everything here is done from Kairo88's own screens, and all of it is kept.

## 1. Add the disks

Copy the game's disks (D88…) into your games folder (a folder of their own keeps them together), then open the library menu › **Refresh**. A game the catalog doesn't know is listed under its file names, one entry per disk.

![Each disk listed on its own](screenshots/add-a-game/01-loose-disks.png)

## 2. Group them into one game

Open the disk the game starts from › **Game settings** (on a two-screen device, Game settings is on the second screen). Under **Library**, **Disks** shows the game's disks.

![The Disks row](screenshots/add-a-game/02-disks-row.png)

Switch on the game's other disks, such as its user disk. They leave the library list and become this game's disks; the row reads "2 disks".

![Grouping the user disk](screenshots/add-a-game/03-group.png)

## 3. Name it

Under **Library**, **Title**: type the game's name and save. **Box art** and **Screenshot** take images from your device.

![Naming the game](screenshots/add-a-game/04-name.png)

The library now lists it once, under its name.

![One game](screenshots/add-a-game/05-one-game.png)

## 4. Choose its drives

The game starts from the disk you grouped the others on, in Drive 1. Under **Machine**, put its other disks where it expects them: here **Drive 2** holds the user disk.

![Drive 2 holds the user disk](screenshots/add-a-game/06-drives.png)

## 5. Firmware

PC-88 games need the machine's BIOS. Library menu › **Machine** › **Firmware** shows whether each file is installed, and which are required; **Import all from a folder…** finds and imports them.

![Firmware](screenshots/add-a-game/07-firmware.png)

## 6. Configure

Everything else in Game settings (controls, BASIC mode, CPU clock, sound, display) is kept for this game alone.

![Game settings](screenshots/add-a-game/08-configure.png)

## 7. Play

Press **Play**.

![The game plays](screenshots/add-a-game/09-plays.png)

In the menu, **Disks** shows each drive.

![Disks](screenshots/add-a-game/10-disks-in-game.png)

Each drive lists the game's disks first, under **This game**, for swapping when it asks.

![Swapping disks](screenshots/add-a-game/11-swap.png)

## 8. It is kept

Save your progress with **Save state**, as with any game. What the game writes to its disks, such as its user disk, is kept too.

![Save state](screenshots/add-a-game/12-save-state.png)

After closing and reopening Kairo88, the game is still one game with its name, disks and settings, and **Load state** brings back your progress.

![Load state after reopening](screenshots/add-a-game/13-load-state.png)
