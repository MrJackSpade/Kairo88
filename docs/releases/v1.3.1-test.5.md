# v1.3.1-test.5

Test build of Kairo88, for PC-88 games. It is not published to Google Play.

- Every PC-88 game in the catalog was test-booted; the games that need particular machine settings get them from the catalog, and each is a game setting you can change.
- Startup commands are typed in full whatever you press meanwhile. The machine runs at full speed only while a line is being typed or a tape is loading, not while it waits for a prompt.
- Startup commands and other text settings can take several lines.
- A long setting value is shortened on its row instead of the setting's name.
- The on-screen keyboard's joystick tab shows a joystick icon.
