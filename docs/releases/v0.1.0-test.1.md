# v0.1.0-test.1

The first test build of Kairo88, for PC-88 games. It is not published to Google Play.

- Runs PC-8801 floppy games (D88) and cassette tape games (T88, CMT): a tape game boots BASIC and types the commands that load it.
- Machine settings for BASIC mode, CPU clock, sound board and the joystick port; the catalog sets them for games that need them.
- A game library with catalog titles, descriptions and artwork, from a folder of your games; archives are read in place.
- Controller, touch and on-screen keyboard controls, with researched defaults and a button mapping for every game.
- Save states, and per-game settings that override the all-games ones.

Games are not supplied. Kairo88 needs the PC-8801 BIOS (N88-BASIC, its extension 0 and the disk sub-system) from your own machine; import it in **Menu › Machine**. Both APK variants have the same features.
