# Google Play listing: Indonesian (id)

- **App name:** Kairo88

## Short description

Mainkan game PC-88 Anda di Android dengan kontrol sentuh atau gamepad.

## Full description

Kairo88 memungkinkan Anda memainkan game PC-88 milik Anda sendiri di Android. Tambahkan image disk atau kaset Anda, pilih game dari pustaka, lalu mainkan dengan gamepad atau kontrol di layar, termasuk keyboard PC-88. Di handheld dua layar, game dan kontrol dapat ditampilkan di layar terpisah.

Game dan BIOS PC-8801 tidak disertakan. Beberapa game memerlukan pengaturan tambahan.

Anda juga dapat mengunduh aplikasi yang sama secara gratis dari GitHub Releases Kairo88. Versi Google Play memiliki fitur yang sama.

Kairo88 adalah proyek independen yang menggunakan QUASI88 dengan emulasi suara ymfm.
