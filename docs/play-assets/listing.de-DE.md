# Google Play listing: German (de-DE)

- **App name:** Kairo88

## Short description

Spielen Sie Ihre PC-88-Spiele auf Android mit Touch-Steuerung oder Gamepad.

## Full description

Mit Kairo88 spielen Sie Ihre eigenen PC-88-Spiele auf Android. Fügen Sie Ihre Disketten- oder Kassettenabbilder hinzu, wählen Sie ein Spiel aus der Bibliothek und spielen Sie mit einem Gamepad oder der Bildschirmsteuerung, einschließlich einer PC-88-Tastatur. Auf einem Handheld mit zwei Bildschirmen lassen sich Spiel und Steuerung auf getrennte Displays verteilen.

Spiele und das PC-8801-BIOS sind nicht enthalten. Manche Spiele brauchen eine zusätzliche Einrichtung.

Sie können dieselbe App auch kostenlos über die GitHub Releases von Kairo88 herunterladen. Die Version bei Google Play hat dieselben Funktionen.

Kairo88 ist ein unabhängiges Projekt auf Basis von QUASI88 mit der Soundemulation ymfm.
