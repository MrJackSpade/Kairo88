# Google Play listing: Russian (ru-RU)

- **App name:** Kairo88

## Short description

Играйте в игры для PC-88 на Android с сенсорным управлением или геймпадом.

## Full description

Kairo88 позволяет играть в ваши собственные игры для PC-88 на Android. Добавьте свои образы дисков или кассет, выберите игру в библиотеке и играйте с геймпадом или с экранным управлением, включая клавиатуру PC-88. На портативных устройствах с двумя экранами игру и управление можно вывести на разные экраны.

Игры и BIOS PC-8801 не входят в комплект. Некоторым играм нужна дополнительная настройка.

Это же приложение можно бесплатно скачать в GitHub Releases Kairo88. В версии из Google Play те же возможности.

Kairo88 — независимый проект на основе QUASI88 с эмуляцией звука ymfm.
