# Google Play listing: Japanese (ja-JP)

- **App name:** Kairo88

## Short description

Android で、お手持ちの PC-88 ゲームをタッチ操作やゲームパッドで遊べます。

## Full description

Kairo88 は、お手持ちの PC-88 ゲームを Android で遊べるアプリです。ディスクイメージやテープイメージを追加してライブラリからゲームを選び、ゲームパッドまたは画面上のコントロール（PC-88 キーボードを含む）で遊べます。2 画面の携帯ゲーム機では、ゲームとコントロールを別々の画面に表示できます。

ゲームと PC-8801 BIOS は含まれていません。一部のゲームには追加の設定が必要です。

同じアプリを Kairo88 の GitHub Releases から無料でダウンロードすることもできます。Play 版にも同じ機能があります。

Kairo88 は、QUASI88 と ymfm のサウンドエミュレーションを使った独立したプロジェクトです。
