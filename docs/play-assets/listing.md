# Google Play listing

- **App name:** Kairo88

- **Price:** US$2.99 (same as Kairo98 and KairoDos)

## Short description

Play your PC-88 games on Android with touch controls or a gamepad.

## Full description

Kairo88 lets you play your own PC-88 games on Android. Add your disk or tape images, pick a game from the library, and play with a gamepad or on-screen controls, including a PC-88 keyboard. On a two-screen handheld, the game and controls can use separate displays.

Games and the PC-8801 BIOS aren't included. Some games need extra setup.

You can also download the same app free from Kairo88 GitHub Releases. The Play version has the same features.

Kairo88 is an independent project using QUASI88 with ymfm sound emulation.
